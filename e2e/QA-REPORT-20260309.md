## 비고 및 확인 제한사항

1. **부제(subtitle) 렌더링**
   - 부제 입력 필드는 존재하나, 현재 템플릿(wedding_classic)에서 프리뷰에 렌더링되지 않음
   - 이는 템플릿 설계 의도로 보이며, 기능 결함이 아님

2. **풀스크린 프리뷰 버튼**
   - 데스크톱 화면에서는 `display: none`으로 숨겨짐
   - 모바일 화면(width ≤ 960px)에서만 표시됨
   - 반응형 설계가 정상 동작함

3. **저장 알림 메시지**
   - "로컬 초안에 저장되었습니다" 메시지가 2초 후 자동으로 사라짐
   - 테스트에서는 저장 버튼 상태 변화로 저장 완료를 검증함

4. **네비게이션 스크롤 스파이**
   - IntersectionObserver 기반으로 동작
   - 스크롤 시 자동으로 활성 섹션이 업데이트됨
   - 클릭 네비게이션도 정상 동작

5. **이미지 업로드 성능**
   - 단일 이미지 업로드: ~3초
   - 다중 이미지 업로드: ~5초
   - 업로드 중 UI 블로킹 없음

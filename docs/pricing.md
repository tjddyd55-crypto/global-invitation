# Pricing & Product Structure

## Pricing Philosophy
- 본 서비스는 1회성 이벤트 중심 서비스이므로 구독 모델을 사용하지 않는다.
- 진입 가격은 낮게 설정하고, 옵션(Add-ons)으로 확장하는 구조를 따른다.
- 모든 가격은 One-time payment 기준이다.

## Core Products

### Simple Message
- Price: $10 (one-time)
- 대상: 감사, 안내, 간단한 메시지 전달
- 포함 기능:
  - 메시지 작성 및 수정
  - 링크 공유
  - 기본 템플릿 사용
- 제외 기능:
  - RSVP
  - 일정/지도
  - 참석자 관리

### Invitation (Base)
- Price: $20 (one-time)
- 대상: 결혼식, 부고, 각종 행사 초대
- 포함 기능:
  - 초대 콘텐츠
  - 일정 정보
  - 장소 지도
  - RSVP (참석/불참)
  - 참석자 수 집계
  - 링크 공유

## Add-ons (Optional, One-time)
모든 Add-ons는 개별 선택 가능하며, 기본 상품과 조합된다.

- Email reminder (D-7 / D-1): +$5
- Schedule / location change notification: +$5
- Guest list export (Excel): +$5
- Guest memo / tag management: +$5
- Donation / gift link (future): +$5
- Media slot expansion (future): +$5

## Price Example
- Invitation Base ($20)
- + Email reminder
- + Change notification
- + Guest list export
= Total $35

## Operational Notes
- Add-ons는 초기에는 UI 및 구조만 제공하고, 결제 로직은 단계적으로 연결한다.
- 실제 결제 연동 시, Lemon Squeezy 상품 또는 가격 옵션으로 매핑한다.
- 가격 변경 시 본 문서를 SSOT로 사용한다.

# Invitation 운영 체크리스트 (비개발자용)

기획자·운영자가 **코드 없이** 초대장 동작을 검증할 수 있는 체크리스트.

**참조**: [INVITATION_FREEZE_STATUS.md](INVITATION_FREEZE_STATUS.md) · [INVITATION_QA_SNAPSHOT.md](INVITATION_QA_SNAPSHOT.md) · [05_UX_TRUST_GUIDE.md](05_UX_TRUST_GUIDE.md)

---

## 1. 날짜/시간/장소 입력 위치

- [ ] **날짜·시간·장소**는 초대장에서 **한 곳(일정 요약 블록)** 에만 “정본”으로 보인다.
- [ ] 같은 내용이 여러 블록에 반복되어 있지 않다.
- [ ] 수정이 필요하면: 에디터/데이터에서 **일정 요약용 필드**만 바꾸면 된다 (다른 곳은 따라감).

---

## 2. Gallery 비어 있을 때 기대 동작

- [ ] 갤러리 이미지가 **하나도 없으면** Gallery **섹션 자체가 안 보인다** (빈 칸도 없음).
- [ ] 이미지가 하나라도 있으면 Gallery 섹션이 보이고, 넣은 이미지만 표시된다.

---

## 3. RSVP 응답 후 재접속 시 화면

- [ ] RSVP에서 이름·참석 여부 제출 후 **같은 브라우저로 다시 들어가면**:
  - [ ] **폼이 비활성**(입력 불가)이고,
  - [ ] **“이미 응답하셨습니다”** 문구 + 잠금 아이콘이 보이며,
  - [ ] 제출한 내용(이름·참석/불참)이 읽기 전용으로 보이고,
  - [ ] **Thank You** 문구가 그대로 보인다.
- [ ] 다른 브라우저/시크릿/다른 기기에서는 “아직 응답 안 함” 상태로 보일 수 있다 (로컬 저장만 사용).

---

## 4. 모바일 스크롤 순서 점검

- [ ] 모바일에서 **위에서 아래로** 스크롤 시 순서:
  1. Hero(대표 이미지·제목)
  2. 일정 요약(날짜·시간·장소)
  3. Location(장소 상세·지도·교통·주차)
  4. Program/캘린더(있을 때만)
  5. Gallery(이미지 있을 때만)
  6. Special Notes(있을 때만)
  7. RSVP(활성일 때만)
  8. 연락처·계좌·방명록·공유
- [ ] 중간에 섹션이 빠지거나 순서가 뒤바뀌지 않는다.
- [ ] 스크롤이 끊기지 않고 자연스럽다.

---

## 5. 공유 미리보기 점검 항목 (문서 기준)

*실제 메타 태그 구현은 없고, 아래 규칙만 문서 기준으로 점검.*

- [ ] **제목(Title)**  
  행사명 + 날짜 느낌으로 보이면 됨 (공유 시 미리보기 제목).
- [ ] **설명(Description)**  
  초대 문구 한 줄 수준으로 요약되면 됨.
- [ ] **썸네일(Thumbnail)**  
  Hero 영역 대표 이미지가 쓰이면 됨.
- [ ] **Hero 화면**  
  타이틀/오버레이만 노출되고, 위 규칙과 화면이 어긋나지 않으면 됨.

---

## 요약

| 항목 | 기대 동작 |
|------|-----------|
| 날짜/시간/장소 | 일정 요약 한 곳만 정본, 중복 없음 |
| Gallery 비어 있음 | Gallery 섹션 미노출 |
| RSVP 재접속 | 폼 비활성 + “이미 응답하셨습니다” + Thank You 유지 |
| 모바일 순서 | Hero → 일정 → Location → … → RSVP → 연락처 등 고정 |
| 공유 미리보기 | 문서 기준 Title/Description/Thumbnail, Hero는 타이틀/오버레이만 |

이 체크리스트만 통과하면 **“이 상태가 정상”** 으로 인 handoff 가능.

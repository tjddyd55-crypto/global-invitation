# Current Development Phase

## Phase Goal
The current goal is NOT to implement payments.

The goal is to prepare for Stripe approval by providing
a minimum public-facing page that explains:
- What the service is
- How users are charged
- Pricing
- Refund policy
- Customer support contact

## Current Tasks
- Create a public /payment-info page
- Make it accessible without login
- Include service description, pricing, refund policy

## Explicitly Out of Scope
The following must NOT be implemented in this phase:
- Stripe API integration
- Checkout or PaymentIntent
- Live account activation
- Card input UI
- Donation, gift money, or money transfer features

프로젝트: Global Invitation (글로벌 모바일 초대장 SaaS)

서비스 개요:
- 사용자가 결혼식/행사/기념일 모바일 초대장을 셀프로 제작하고 링크로 공유하는 서비스
- 초대장은 디지털 콘텐츠이며 물리적 상품 없음
- 결제 모델(추후): 초대장 1개당 단건 결제(USD $39)로 공유 권한 unlock
- 현재는 결제 연동 금지(Stripe API/Checkout 구현 금지). 결제는 “자리”만 만든다.

현재 완료된 것:
- /payment-info 승인용 페이지 배포 완료

개발 원칙:
- 단계별로 최소 기능만 구현
- 추측 금지 / 임의 기능 추가 금지
- 각 Step 완료 후 체크리스트로 검증하고 다음 Step 진행
- 축의금/부의금/송금/기부 기능은 2차(이번 MVP 범위 아님)
